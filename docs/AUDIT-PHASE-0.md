# Phase 0 audit

Scope: everything in the repository, checked against `Doc.md`. Date: 2026-10-20.

## Verdict

The repository is **Phase 0 (scaffolding) only**: Phases 1 to 6 of `Doc.md` section 15 (auth, payments, ledger endpoints, importer, notifications, jobs, governance, assets/NAV, reconciliation, backups, hardening) are not built. That is expected for a phase-by-phase plan and is listed in the coverage table below.

The Phase 0 that was delivered **did not meet its own acceptance criteria** (`pnpm check` green, stack starts from scratch, migrations apply to an empty database). It could not install (missing `packages/shared/package.json`, a non-existent dependency version), its production image could not run, and the ledger had real integrity bugs. All of that is now fixed and covered by tests; what remains is listed under "Not verified" and "Open items".

## Not verified (could not be in this environment)

- **Docker**: the daemon was not running. The images were not built; the Dockerfile, compose files and `10-roles.sh` were reviewed and their parts exercised separately (bundle, `pnpm deploy`, migrate, healthcheck, role grants), not as a whole.
- **PostgreSQL**: tests ran on an embedded PostgreSQL 18 binary, not 16 with Testcontainers. Nothing used is version-specific, but run the suite once on 16 (`docker` + `pnpm test`).
- **Android**: no SDK; the native project and release script are untested. **Browsers/Playwright**: not run; the service worker was inspected, not executed.
- The reference design in `design/` (and `docs/UI-NOTES.md`) named in 19.6 is not in the repository, so UI conformance could not be checked.
